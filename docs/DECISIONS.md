**D27. ## Архитектура и технологии

**D9. Local-first: данные только в AsyncStorage, без backend — CURRENT.** Доступ к данным только через `AppDataContext`; всё хранилище инкапсулировано в `storage.ts`, чтобы подключить Firebase заменой одного файла.
- SUPERSEDED: «хранение в памяти» из ТЗ от 22.09.

**D10. Времена намаза — офлайн через `adhan` — CURRENT.** SUPERSEDED: внешний API (Aladhan) с кэшем на месяц (Исламское дополнение). Причина: работает без интернета, без лимитов.

**D11. AsyncStorage 2.2.0 — CURRENT.** SUPERSEDED: `^3.1.1` (мастер-промпт). Причина: Expo Go SDK 57 содержит нативный модуль 2.x; 3.x ищет другой модуль, и в Expo Go любые чтения/записи падали.

**D12. Зависимости — строго версии Expo SDK (`npx expo install`, `expo-doctor`); транзитивные `react-native-reanimated`/`react-native-worklets` закреплены версиями SDK; Node 24.21.0 и на Mac, и на EAS — CURRENT.** Причина: несовпадение lock-файла ломало `npm ci` на EAS; версии вне SDK рискуют упасть в Expo Go.

**D13. Без нативных зависимостей вне Expo Go — CURRENT.** Свои пикеры, сетки, markdown-редактор (без WebView). SUPERSEDED: `react-native-calendars`, `@react-native-community/datetimepicker` (кандидаты из ТЗ от 22.09).

**D26. Жесты листания — встроенные `PanResponder` + `Animated` — SUPERSEDED** (заменено D28, 28.09.2026): с появлением свайпа вкладок два жеста нужно согласовывать, а `PanResponder` не умеет блокировать нативный/чужой жест.

**D28. Жесты — `react-native-gesture-handler` (~2.32, версия SDK 57) + Reanimated; пейджер вкладок свой, а не `react-native-pager-view` — CURRENT** (28.09.2026). Причина: у pager-view нет веба, а внутренние листалки дат должны блокировать жест вкладок (`blocksExternalGesture`) — это надёжно, только когда оба жеста в gesture-handler. Оба пакета есть в Expo Go.

**D14. Иконки — `lucide-react-native` — CURRENT.** SUPERSEDED: `@react-native-vector-icons/ionicons` (сам заменил устаревающий `@expo/vector-icons`); удалён при переходе на Notion Dark.

**D15. UI-система: цвета только из `src/theme/colors.ts`; `Text`/`TextInput`/`Switch` — из `themed.tsx`; без теней, радиус ≤ 8 — CURRENT.** Причина: централизованная правка темы и отсутствие «чёрного текста на тёмном фоне».

**D16. Уведомления: детерминированные идентификаторы по сущности, id не хранятся в данных; полная пересборка при старте с учётом лимита iOS 64 — CURRENT.** SUPERSEDED: поле `notificationId` у задачи (мастер-промпт).

**D17. Срок задачи хранится как дата `YYYY-MM-DD` + время `HH:mm` в локальном времени — CURRENT.** SUPERSEDED: ISO-момент `dueDate`. Причина: задача «на день» не должна съезжать при смене часового пояса.

**D18. Изменения формата данных — только через миграции (`SCHEMA_VERSION`) — CURRENT.**

**D19. Дата по хиджре — Intl (Умм аль-Кура) с проверкой на известной дате, запасной — табличный календарь — CURRENT.** Причина: поддержка исламского календаря в Hermes различается между iOS и Android.

**D20. Сборки — EAS Build, организация `sirahdo`; ключ подписи Android хранится в EAS — CURRENT.** Все APK подписаны одним ключом → ставятся поверх как обновление.

**D21. Документация проекта: CLAUDE.md (правила) + SPEC/spec (что) + TECH_STACK (на чём) + ARCHITECTURE (как устроено) + PROJECT_STATE (где мы) + DECISIONS (почему) — CURRENT** (25.09.2026). SUPERSEDED: единый `docs/TZ.md` (есть в коммите `edcbf67`).
