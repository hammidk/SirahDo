# SirahDo — ТЗ продукта (актуальное)

Источник истины о том, ЧТО делает приложение. Живой документ: при изменении требования старое заменяется новым (история — в Git).
Детали по функциональным модулям — в `docs/spec/`.

## Назначение

**Простой планер дня мусульманина.** День разбит на 5 окон между намазами; в этих окнах живут задачи и привычки.
Целевой пользователь — обычный практикующий мусульманин, а не менеджер проектов: он хочет видеть свой день, не забывать дела и держать регулярные поклонения.

Три модуля:

1. **Календарь / Сегодня** — день по окнам намаза (вкладки «Сегодня» и «Календарь»).
2. **Простые задачи** — Входящие и списки без вложенности (вкладка «Задачи»).
3. **Трекер привычек** — с готовыми исламскими привычками (вкладка «Трекер»).

**Главное отличие — связка с намазом** ([spec/windows.md](spec/windows.md)): задача и привычка привязываются к окну намаза, напоминание ставится относительно времени намаза, а не только по часам, и есть готовые исламские привычки (азкары утром и вечером, Коран, сунна-намазы, пост в понедельник и четверг, витр).

## Принципы (для любой функции)

1. **Простота для обычного пользователя — главный критерий.** Функция, которую нужно объяснять, не добавляется. Режимов «для продвинутых» нет.
2. День строится вокруг 5 окон между намазами. Намазы — несдвигаемые якоря.
3. Задачи и привычки живут внутри окон намаза. Привязка необязательна: дело без окна — просто «в течение дня».
4. Привычки — постепенно, без штрафов и «красных» индикаторов за пропуск.
5. Приложение ничего не меняет в данных пользователя без его явного действия.
6. Всё работает офлайн; данные хранятся только на устройстве.

## Навигация

Верхняя панель (нижнего таб-бара нет): **аватар** + 4 вкладки-таблетки **Сегодня / Трекер / Календарь / Задачи**; вкладки листаются свайпом по экрану — подробно в [spec/navigation.md](spec/navigation.md).
- Входящие и списки — во вкладке «Задачи».
- Профиль, Настройки намаза, Уведомления, Помощь — меню аватара.
- При первом запуске — онбординг (приветствие → местоположение → метод расчёта → готовые привычки).
- Плавающая кнопка «+» контекстная: Сегодня / Задачи / Входящие / список → задача (с подставленными по контексту датой, окном намаза, списком); Календарь → событие; Трекер → привычка.

## Ключевые понятия (не путать)

- **Окно намаза** — промежуток между двумя соседними намазами; их 5 в сутках ([spec/prayer-profile.md](spec/prayer-profile.md)). К окну привязываются задачи и привычки ([spec/windows.md](spec/windows.md)).
- **Входящие** — задачи без списка. Не путать с блоком «В течение дня» на «Сегодня» — там дела на сегодня без окна намаза.
- **Список** — простая группа задач без вложенности и разделов (в данных и коде сущность называется `Project`).
- **Готовая привычка** — привычка из встроенного набора исламских привычек с уже заполненными полями; после добавления — обычная привычка.
- **День привычек** — длится от Фаджра до Фаджра: отметка до Фаджра засчитывается предыдущему дню ([spec/habits.md](spec/habits.md)). У задач, событий и в Календаре день обычный — меняется в полночь.

## Общие механизмы

- **Повторение** (задача и событие): пресеты «Не повторять / Каждый день / По будням / Каждую неделю (в этот день) / Каждый месяц / Каждый год» + гибкая настройка: интервал N дней/недель/месяцев/лет, дни недели (для недель), окончание — никогда / до даты / N раз. Ежемесячно 31-го — месяцы без 31-го пропускаются; ежегодно 29 февраля — только високосные годы.
- **Напоминания** — локальные уведомления, несколько на объект. Тап по уведомлению задачи открывает задачу. Изменение, выполнение и удаление снимает старые уведомления.
  - Задача и событие: в момент срока/начала, за 5 / 10 / 30 мин, за 1 час, за 1 день; своё смещение (мин/ч/дн); точное время.
  - Привычка: время суток в свои дни недели.
  - Задача и привычка: **от времени намаза** — до, после или в момент выбранного намаза ([spec/windows.md](spec/windows.md)).

## Чего в продукте нет (сознательно)

Чтобы продукт оставался простым, в нём нет (решение D33 в [DECISIONS.md](DECISIONS.md)): вложенных проектов и разделов; модели «Намерение → Действие → Упование»; полей Ценность, Ожидаемый результат, Приоритет, Длительность, Сфера; тегов (включая тег намерения) и фильтров; чек-листа, кнопки «Начать», итога и причины переноса у задачи; расширенного режима; ИИ и его заглушек; разделов «Дневник» и «История»; статистики привычек; режима «Расписание» в Календаре. Возвращать их — только отдельным решением пользователя.

## Вне MVP

Облачная синхронизация (Firebase), серверные push-уведомления, вложения-файлы в событиях, мягкое удаление (Корзина), светлая тема.
