# SirahDo — ТЗ продукта (актуальное)

Источник истины о том, ЧТО делает приложение. Живой документ: при изменении требования старое заменяется новым (история — в Git).
Детали по функциональным модулям — в `docs/spec/`.

## Назначение

Не очередной to-do, а помощник мусульманину осознанно распоряжаться временем: день строится вокруг намазов, свободное время видно как возможность наполнить его благом, привычки внедряются постепенно, вечером — разбор дня.
Миссия: помочь выполнять обязательное, постепенно внедрять полезные привычки, развиваться в сферах жизни и регулярно возвращаться к поминанию Аллаха.

## Принципы (для любой функции)

1. День строится вокруг 5 окон между намазами. Намазы — несдвигаемые якоря.
2. **Приложение рекомендует, а не решает.** Никакая автоматика или ИИ не меняет данные пользователя без его явного действия.
3. Свободное время показывается как возможность наполнить его благом.
4. Привычки — постепенно, без штрафов и «красных» индикаторов за пропуск.
5. После задачи можно коротко проанализировать результат (всегда по желанию).
6. Вечером — анализ дня и дневник.

## Навигация

Верхняя панель (нижнего таб-бара нет): **аватар** + 4 вкладки-таблетки **Сегодня / Трекер / Календарь / Проекты**; вкладки листаются свайпом по экрану — подробно в [spec/navigation.md](spec/navigation.md).
- Входящие, Дневник, История — строки во вкладке «Проекты».
- Профиль, Настройки намаза, Расширенный режим, Уведомления, Помощь — меню аватара.
- При первом запуске — онбординг (приветствие → местоположение → метод расчёта).
- Интерфейс по умолчанию простой; продвинутые поля — в **Расширенном режиме** ([spec/modes.md](spec/modes.md)).
- Плавающая кнопка «+» контекстная: Сегодня/Проекты/Входящие/проект/тег → задача (с подставленными датой, окном, проектом, разделом, тегом по контексту); Календарь → событие; Трекер → привычка.

## Справочники (фиксированные, заданы в коде)

- **Сферы жизни:** Вера, Здоровье, Ризк, Семья, Благотворительность, Цели / Идеи / Прочее. Используются у задачи и проекта (видны в расширенном режиме).
- **Теги намерения:** Ибада, Дунья, Обязательство — фиксированный чип у задачи и проекта. Не путать со свободными пользовательскими тегами и с полем «Намерение» проекта/раздела.
- **Приоритет:** П1 (высший) … П4 (по умолчанию, «без приоритета»), как в Todoist.

## Ключевые понятия (не путать)

- **Намерение** — зачем существует проект/раздел (уровень проекта). **Ценность** — ради чего выполняется конкретная задача (уровень задачи). Разные поля, не объединять.
- **Входящие** — временный буфер задач без проекта (не путать с блоком «Без времени» на «Сегодня» — это задачи на сегодня без указанного времени).
- **Упование** — блок будущих ИИ-рекомендаций в карточке проекта (сейчас заглушка).

## Общие механизмы

- **Повторение** (задача и событие): пресеты «Не повторять / Каждый день / По будням / Каждую неделю (в этот день) / Каждый месяц / Каждый год» + гибкая настройка: интервал N дней/недель/месяцев/лет, дни недели (для недель), окончание — никогда / до даты / N раз. Ежемесячно 31-го — месяцы без 31-го пропускаются; ежегодно 29 февраля — только високосные годы.
- **Напоминания** (задача и событие): несколько на объект. Быстро — в момент срока/начала, за 5 / 10 / 30 мин, за 1 час, за 1 день; своё смещение (мин/ч/дн); точное время. Привычки — время суток в свои дни недели. Локальные уведомления; тап по уведомлению задачи открывает задачу. Изменение, выполнение и удаление снимает старые уведомления.
- **ИИ** — только заглушки без логики: блок «Упование» в карточке проекта. Бэклог: пересборка дня при пропуске намаза (только как предложение с подтверждением), уточнение намерения при создании задачи (всегда пропускаемое), рекомендации дуа/азкаров/доп. намазов.

## Вне MVP

Реальный ИИ, облачная синхронизация (Firebase), серверные push-уведомления, вложения-файлы в событиях, совместные проекты, светлая тема.
