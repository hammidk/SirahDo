# Календарь

Ориентир — Notion Calendar (вид) и Google Calendar (функции).

## Экран

- В шапке — период (день / неделя / месяц); тап раскрывает сетку месяца для быстрого перехода к дате (месяцы в ней листаются стрелками и горизонтальным свайпом). Слева — гамбургер (панель), справа — «Сегодня»: обычный текст на плашке bg-hover, без синего; если выбран сегодняшний день — приглушён. Под шапкой — стрелки назад/вперёд по периоду.
- **Горизонтальный свайп** по области просмотра листает период текущего режима: «День» — на день, «Неделя» — на неделю, «Месяц» — на месяц, «Расписание» — на неделю (как стрелки). Контент уезжает за пальцем, новый период въезжает с другой стороны.
- Для прошедшего дня в режиме «День» — ссылка «История дня →».
- «+» — новое событие на выбранную дату (ближайший час). Тап по пустому часу шкалы — событие на этот час.

## Режимы (выбор в боковой панели, запоминается)

- **Расписание:** 30 дней от выбранной даты, только дни с записями (и сегодня); у дня — дата, хиджра, строка времён намазов, события и задачи. Сегодняшняя дата выделена фоном, а не цветом текста.
- **День / Неделя:** шкала 0–24 ч; строка «весь день» (события на весь день, задачи без времени); события и задачи со временем — блоками (задача — длительностью, по умолчанию 30 мин); пересекающиеся — рядом в колонках; **намазы — несдвигаемые линии-якоря** с подписью (в «Неделе» без подписи); линия текущего времени. Неделя — Пн–Вс, заголовок дня ведёт в «День».
- **Месяц:** сетка 6 недель, до 3 записей в ячейке + «+N»; тап по дню → режим «День».

## Боковая панель

Режим просмотра; список календарей с чекбоксами (любая комбинация видимых); слой «Задачи со сроком» (вкл/выкл); «Создать календарь»; «…» у календаря — название, цвет, удаление (вместе с его событиями; последний календарь удалить нельзя). По умолчанию существует календарь «Личный».

## Событие

Форма: название; «Весь день»; начало и конец (смена начала сдвигает конец, сохраняя длительность; конец раньше начала исправляется); повтор; календарь; цвет события (или цвет календаря); уведомления (у нового события по умолчанию «за 10 мин»); локация; описание; вложения — **только ссылки** (файлы — вне MVP).
- Правка и удаление **повторяющегося события относятся ко всей серии**.
- Многодневные события показываются в каждом дне своего диапазона.
- Уведомления повторяющихся событий планируются на ближайшие 14 дней и продлеваются при открытии приложения.
