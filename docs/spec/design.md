# Внешний вид — Notion Dark

Интерфейс визуально следует Notion в тёмной теме. **Тёмная тема — единственная** (светлая — вне MVP).
Реализация токенов и компонентов — см. раздел «UI-система» в [../ARCHITECTURE.md](../ARCHITECTURE.md).

## Палитра

| Токен | Цвет | Назначение |
|---|---|---|
| bg-primary | #191919 | фон приложения |
| bg-secondary | #202020 | карточки, панели, модалки, поля |
| bg-hover | #2A2A2A | нажатие/выбор, фон чипов |
| bg-elevated | #252525 | всплывающие меню, плашки |
| border | #2F2F2F | разделители |
| border-subtle | rgba(255,255,255,0.055) | самые тонкие линии |
| text-primary / secondary / tertiary / disabled | #E8E6E3 / #9B9B9B / #6F6F6F / #4D4D4D | текст |
| accent blue / green / red / yellow / purple | #529CCA / #4DAB9A / #E06C75 / #C9A227 / #9A6DD7 | ссылки и активное / выполнено / ошибки и просрочка / намаз-акцент / теги и ИИ |

Никакого чистого чёрного и чистого белого. «Тег» в стиле Notion: фон цвета на 15% прозрачности + текст этого цвета.
Цвета календарей/тегов/событий — приглушённая палитра категорий (синий, зелёный, жёлтый, красный, фиолетовый, оранжевый, коричневый, серый).
Смысловые цвета: приоритеты П1 красный, П2 жёлтый, П3 синий, П4 третичный; намаз и окна — жёлтый акцент; выполнено — зелёный.

## Типографика

Системный шрифт (без кастомных). Заголовок экрана 24–28 / 600–700; заголовок секции 16–18 / 600; текст 15; вторичный 12–13. Без letter-spacing и без капса в подписях.

## Компоненты и правила

- **Плоско:** никаких теней; глубина — только фоном (primary → secondary → elevated). Радиус 6–8 (круги — круги).
- **Списки:** строки разделены тонкой линией, не карточками с обводкой; нажатие — фон bg-hover, без масштабирования.
- **Чекбокс задачи:** круг с тонкой обводкой (цвет — приоритет); выполнено — зелёная заливка с галочкой, текст зачёркнут и приглушён.
- **Чипы:** компактные, фон bg-hover, текст вторичный; выбранный — цвет категории 15% + текст цвета.
- **Кнопки:** primary — светлая на тёмном (фон text-primary, тёмный текст); secondary/ghost — прозрачная с тонкой обводкой; danger — как ghost с красным текстом.
- **Поля ввода:** фон bg-secondary без рамки; в фокусе — тонкая синяя обводка; плейсхолдер — tertiary. Встроенные поля (заголовок в листе, пункт чек-листа) — без обводки.
- **Иконки:** тонкие line-иконки Lucide, монохромные (вторичный текст); активное — светлый текст или акцент. Иконки привычек — тоже line-иконки (набор из 21), в цвете привычки. Эмодзи в интерфейсе не используются.
- **Таб-бар:** фон сливается с экраном, тончайшая линия сверху; активная вкладка — светлые иконка и текст, неактивные — tertiary; без цветных индикаторов.
- **Модалки и карточки:** нижние листы и полноэкранные карточки на bg-secondary/primary; свойства задачи — строки «иконка · название — значение» с тонкими разделителями (как свойства страницы Notion).
- **Намаз:** блок-ориентир на «Сегодня» — фон bg-hover + жёлтая полоска слева и тонкая полоса прогресса; на шкалах — тонкие жёлтые линии-якоря. Без ярких заливок.
- **«Сегодня» и текущая дата** выделяются фоном-плашкой или весом шрифта, а не цветным (синим) текстом; синий — только для ссылок и выбранного/активного элемента.
- **Сворачиваемые секции** (как в Todoist): заголовок «Название · N», шеврон поворачивается, высота анимируется плавно; действие секции — справа от заголовка.
- **Листание периодов** (день / неделя / месяц): горизонтальный свайп, контент едет за пальцем; стрелки остаются.
- **Карточки привычек:** плашка bg-secondary, заливка прогресса цветом привычки на ~22% слева направо, плавно; выполненная — залита полностью, кнопка — круг цвета привычки.
- **Формы из секций** (привычка): каждая секция — карточка bg-secondary с заголовком 15/600 и подсказкой 12; крупные элементы управления (степпер, кружки дней, «пилюли» времени), а не мелкий текст.
- Текст на заливке цветом категории — тёмный; на тёмных тонах (коричневый) — светлый.
- **Плавающая «+»:** круг bg-elevated с тонкой обводкой, без тени.
- Вёрстка плотная: отступы 12–16.
