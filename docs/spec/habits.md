# Трекер привычек

Принцип — постепенность без наказаний: пропущенный день нейтральный (не красный), рядом с текущей серией всегда видна лучшая.

## Экран «Трекер»

- **Неделя** (Пн–Вс, листается): кружок на каждый день; заливка = доля выполненного по запланированным привычкам (частичное выполнение засчитывается долей); все выполнены — зелёный с галочкой; дней без плана — пунктирный кружок. Тап — выбрать день.
- **Список на выбранный день:** запланированные привычки. Строка: иконка, название, «N из цели», серия, лучшая серия, сфера, прогресс. Кнопка справа: для цели 1 — переключатель выполнено/нет; для цели >1 — «+1» (и «−» при N>0). Будущие дни — только просмотр. Тап по строке — редактирование.
- «Не по плану в этот день» — привычки, не запланированные на выбранный день.
- Шапка — «Статистика». «+» — новая привычка.

## Привычка

Название + иконка (эмодзи из набора или свой), описание, сфера, **цель повторений в день** (по умолчанию 1; например «Зикр после намаза — 5»), **дни недели** (быстро: каждый день / по будням / Пн и Чт), напоминания — время суток в её дни (несколько). «Пауза (в архиве)» — скрывает из трекера, история сохраняется. Удаление удаляет и историю отметок.

## Правила подсчёта

- Привычка запланирована на дату, если день недели в её расписании и дата не раньше создания привычки.
- День выполнен, если отметок ≥ цели.
- **Серия** — подряд выполненные запланированные дни назад от сегодня; сегодняшний невыполненный день серию не рвёт; незапланированные дни пропускаются.
- **Лучшая серия** — максимум за всё время.

## Статистика

Период: неделя / месяц / год (последние 52 недели). Общий процент выполнения запланированного, теплокарта дней, строка по каждой привычке: процент, «X из Y дн.», лучшая серия, всего отметок (для цели >1). Подпись: «Пропуски не обнуляют путь».
