# Дневник и История

## Дневник

- Одна запись на дату: «Как прошёл день» (свободный текст), «Что получилось», «Что изменить завтра», «Благодарность». Сверху — сводка дня: выполненные задачи (до 5 названий) и привычки.
- Открывается из вечернего блока «Сегодня», из вкладки «Проекты» (список записей, новые сверху, кнопка записи за сегодня) и из Истории дня.
- Запись можно удалить.

## История

- Список прожитых дней (новые сверху, по 30, «Показать ещё»): дата и хиджра; сводка — ✓ выполнено, ↷ перенесено, ○ не сделано, привычки X/Y, отметка дневника; первые названия выполненных задач. День без записей — «Тихий день».
- **День истории:**
  - Выполнено — задачи с временем начала–окончания, Ценностью и итогом-комментарием.
  - Перенесено — задачи, срок которых стоял на этот день и был сдвинут позже (куда перенесена, причина).
  - Не сделано — активные задачи со сроком на этот прошедший день; кнопка «На сегодня».
  - Привычки — запланированные и отмеченные в этот день.
  - Дневник — запись или предложение написать.
- Открывается из вкладки «Проекты» и из Календаря (режим «День» для прошедшей даты).
