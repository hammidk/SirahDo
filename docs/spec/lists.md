# Вкладка «Задачи»: Входящие и списки

Сверху вниз: **строка поиска** → **Входящие** (счётчик) → **Избранное** (если есть списки со звёздочкой) → **Списки** (счётчик активных задач у каждого; «+» — новый список) → ссылка «Архив списков (N)», если есть архивные. «+» внизу — задача во Входящие.

- Списки плоские: вложенности, папок и разделов нет.
- **Поиск** — по мере ввода вместо обычного содержимого показываются найденные списки (не архивные) и активные задачи (по названию и описанию, до 50); без учёта регистра и «ё». Пусто — «Ничего не найдено».

## Входящие

Задачи без списка — место, куда быстро записать дело. У каждой задачи кнопка «→» (разбор): выбрать список — задача переносится сразу; либо назначить окно намаза на сегодня (задача остаётся во Входящих, получает срок «сегодня» и появляется на «Сегодня» в этом окне).

## Список

- Экран списка: название, активные задачи, «Показать выполненные (N)». «+» — задача в этот список.
- Шапка: звезда — избранное; тап по названию — переименование; «настройки»: «В архив», «Удалить».
- **Удаление списка** удаляет все его задачи — после подтверждения с подсчётом, что удалится (с советом отправить в архив, если список просто больше не нужен).
- **Архив:** архивный список скрыт из вкладки «Задачи» и из выбора списка у задачи; на экране «Архив списков» — «Вернуть» или «Удалить».
