# Простой и расширенный режим

Целевой пользователь — практикующий мусульманин, а не менеджер проектов. По умолчанию интерфейс простой; продвинутые функции спрятаны, но доступны: **Расширенный режим** включается переключателем в меню аватара (`advancedMode`, по умолчанию выключен).

**Выключение режима ничего не удаляет:** заполненные поля (Намерение, разделы, Ценность и т.д.) остаются в данных, просто не показываются, и снова видны при включении.

## Что видно

| Место | Простой режим | Расширенный режим добавляет |
|---|---|---|
| Полная карточка задачи | Название; **Срок**; **Окно намаза**; **Проект** (по умолчанию «Входящие»); **Напоминания**; кнопка **«Ещё»** (рядом — что из спрятанного заполнено) раскрывает: Описание, «Начать», Чек-лист, Повтор, Приоритет, Теги, Длительность | «Ещё» всегда раскрыто; Раздел; Сфера жизни; Тег намерения; Ценность; Ожидаемый результат |
| Компактный вид задачи | Чипы Срок / Окно намаза / Проект / Напоминание; чип «Ещё» → описание, Приоритет, Теги | Описание и все чипы сразу; Сфера; выбор раздела у проекта |
| Строка задачи в списке | срок, напоминания, окно, чек-лист, приоритет, теги, проект | сфера, тег намерения, Ценность |
| Проект | Название + список задач (задачи из разделов — общим списком) и «Показать выполненные»; в настройках — папка, архив, удаление | Намерение, подпроекты, разделы (со своим Намерением), Упование; сфера и тег намерения |
| Проекты (вкладка) | Поиск, Входящие, Дневник, История, Избранное, проекты | Блок «Фильтры и теги» |

Допущение: задание называло для «Ещё» Описание, Приоритет, Тег и Длительность; Повтор и Чек-лист тоже положены под «Ещё» (а не только в расширенный режим) — они нужны и в простом использовании (ежедневные азкары, список покупок). В компактном виде длительности нет — она в полной карточке.

## Окно намаза у задачи

Если у срока указано **время**, окно намаза подставляется автоматически — то, в которое попадает это время (до Фаджра — ночное «Иша → Фаджр» прошлых суток); вручную его не выбирают. Без времени окно выбирается вручную (или не выбирается).
