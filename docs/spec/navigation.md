# Навигация, меню аватара, онбординг

## Верхняя панель (вместо нижнего таб-бара)

Нижнего таб-бара нет. Вверху главного экрана, под статус-баром, одна строка: **аватар** слева и 4 вкладки-«таблетки»:

1. **Сегодня** — иконка дома
2. **Трекер** — галочка в круге
3. **Календарь** — календарь
4. **Задачи** — лоток «Входящие» (внутри: поиск, Входящие, списки)

- Активная вкладка — иконка + подпись, фон `#2F2F2F`, форма pill высотой 44. Неактивные — только иконка в круге 44×44 на `#252525`, иконка вторичного цвета.
- Ширина, фон и подпись таблеток меняются плавно и **синхронно с прогрессом свайпа** (активная сужается до круга, новая расширяется и показывает подпись).
- Аватар — круг 40: первая буква имени из Профиля или нейтральная иконка. Тап — меню аватара.

## Переключение вкладок

- **Свайп по экрану** влево — следующая вкладка, вправо — предыдущая; контент идёт за пальцем, быстрый рывок листает даже при малом сдвиге. На крайних вкладках — упругий отскок, без зацикливания.
- **Тап по таблетке** — анимированный переход к вкладке.
- **Приоритет жестов:** внутри областей со своим горизонтальным листанием дат свайп листает даты, а не вкладки — это вся область просмотра Календаря (день/неделя/месяц), сетка месяца в пикере даты и строка недели в Трекере. На остальной части экрана (шапки страниц, пустые зоны, списки) и по самой верхней панели свайп переключает вкладки. Вертикальная прокрутка страниц не мешает: горизонтальный жест начинается только при явно горизонтальном движении.

## Меню аватара

Поповер под аватаром (не полноэкранная модалка): фон bg-secondary, радиус 24, тонкая обводка, крупные пункты (иконка + текст 17), без теней, затемнение экрана. Закрывается тапом вне поповера или свайпом вниз.

1. **Профиль** (подпись — город) → экран «Профиль»: имя, местоположение (GPS / город).
2. — разделитель —
3. **Настройки намаза** → метод расчёта, мазхаб, поправка хиджры, город.
4. **Уведомления** → состояние разрешения («Разрешить» / «Открыть настройки телефона») и как работают напоминания.
5. **Корзина** — неактивна с подписью «Скоро» (мягкого удаления пока нет; удаление задач окончательное, с подтверждением).
6. **Помощь** → короткие ответы: вкладки и свайпы, Сегодня и окна намаза, задачи и списки, трекер и готовые привычки, где хранятся данные.

## Онбординг первого запуска

Показывается, если онбординг не пройден и местоположение не задано (у тех, кто уже пользуется приложением с выбранным городом, его не будет):

1. **Приветствие:** «День, построенный вокруг намаза» → «Начать».
2. **Местоположение:** «Определить автоматически» (GPS) или «Выбрать город вручную»; можно «Позже».
3. **Метод расчёта** — предвыбран по стране места (Турция — Diyanet, Саудовская Аравия — Умм аль-Кура, ОАЭ — Dubai, Египет — Egyptian, Пакистан/Индия/Бангладеш/Афганистан — Karachi, США/Канада — ISNA, остальные — Muslim World League); «Далее» или «Пропустить» (оставляет предвыбранный).
4. **Готовые привычки:** набор исламских привычек ([habits.md](habits.md)) списком с переключателями, заранее ничего не выбрано; «Готово» добавляет отмеченные, «Пропустить» — ни одной. Добавить их позже можно в Трекере.

Дальше — «Сегодня».
