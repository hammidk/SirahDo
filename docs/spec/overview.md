# Проекты (Todo)

## Вкладка «Проекты» (бывший «Обзор»)

Сверху вниз: **строка поиска** → группа **Входящие (счётчик) / Дневник / История** → блок **Фильтры и теги** (переход на отдельный экран; **только в расширенном режиме**, см. [modes.md](modes.md)) → **Избранное** (если есть: проекты и теги со звёздочкой) → **Проекты** (дерево папок, счётчик активных задач, «+» — новый проект с выбором родительской папки) → ссылка «Архив проектов (N)», если есть архивные. «+» внизу — задача во Входящие.

- Все строки выровнены по одной сетке отступов (эталон — строки «Избранного»); вложенные папки сдвинуты на уровень; шеврон сворачивания ветки — справа в строке папки.
- **Поиск** — по мере ввода вместо обычного содержимого показываются найденные проекты (не архивные), теги и активные задачи (по названию и описанию, до 50); без учёта регистра и «ё». Пусто — «Ничего не найдено».

## Фильтры и теги

Отдельный экран с развёрнутыми списками: **Фильтры** (4, со счётчиками) и **Теги** (со счётчиками, «+» — новый тег; тап — экран тега).

## Входящие

Временный буфер активных задач без проекта. У каждой задачи кнопка «→» (разбор): выбрать проект (дерево), затем раздел (если есть) — задача переносится сразу; либо назначить окно намаза на сегодня (задача остаётся во Входящих, но появляется на «Сегодня» в этом окне).

## Проекты и разделы

- Проекты — папки с вложенностью; в модели глубина не ограничена, в интерфейсе — **до 3 уровней** (перенос в папку разрешён, только если всё поддерево влезает в лимит).
- Карточка проекта — модель **«Намерение → Действие → Упование»**:
  1. **Намерение** — свободный текст «зачем», необязательный; в свёрнутом виде — первая строка + «ещё», по тапу раскрывается; карандаш — редактирование.
  2. **Подпроекты** (если есть или глубина позволяет — «+ Подпроект»).
  3. **Действие** — задачи без раздела, затем разделы (как в Todoist). У раздела: своё Намерение (такое же поведение), «+» задача в раздел, меню «…»: переименовать, удалить.
  4. «Показать выполненные (N)».
  5. **Упование** — заглушка ИИ-рекомендаций (дуа, доп. намаз, азкары), без логики.
- **Простой режим:** экран проекта — название и список задач (задачи из разделов — общим списком), «Показать выполненные». Намерение, подпроекты, разделы, Упование, сфера и тег намерения — только в расширенном режиме ([modes.md](modes.md)).
- Шапка проекта: название родителя; звезда — избранное; «настройки»: папка, (в расширенном режиме — сфера, тег намерения), «В архив», «Удалить». Тап по названию — переименование.
- **Удаление проекта** удаляет его подпроекты, разделы и все их задачи — после подтверждения с подсчётом, что удалится (с советом отправить в архив, если проект просто завершён).
- **Удаление раздела** — задачи остаются в проекте без раздела.
- **Архив:** архивный проект скрыт из вкладки «Проекты» и выбора проекта; на экране «Архив проектов» — «Вернуть» или «Удалить».

## Теги

Пользовательские теги (имя уникально без учёта регистра; создаются в задаче или на экране «Фильтры и теги»). Экран тега: активные задачи с тегом, избранное, цвет (палитра категорий), переименование, удаление (задачи остаются, тег у них пропадает); «+» — задача с этим тегом.

## Фильтры

Фиксированный список из 4 фильтров по сроку — **Сегодня / Ближайшие 7 дней** (сегодня + 6 дней) **/ Просрочено / Без срока**. Новые фильтры не создаются, существующие не редактируются и не удаляются. Экран фильтра — живой список подходящих активных задач (по сроку, затем по приоритету).
