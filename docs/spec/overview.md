# Обзор (Todo)

## Экран «Обзор»

Сверху вниз: группа **Входящие (счётчик) / Дневник / История** → **Избранное** (если есть: проекты, фильтры, теги со звёздочкой) → **Проекты** (дерево папок, сворачивание веток, счётчик активных задач, «+» — новый проект с выбором родительской папки) → ссылка «Архив проектов (N)», если есть архивные → **Фильтры** («+» — новый) → **Теги** (со счётчиками, «+» — новый). «+» внизу — задача во Входящие.

## Входящие

Временный буфер активных задач без проекта. У каждой задачи кнопка «→» (разбор): выбрать проект (дерево), затем раздел (если есть) — задача переносится сразу; либо назначить окно намаза на сегодня (задача остаётся во Входящих, но появляется на «Сегодня» в этом окне).

## Проекты и разделы

- Проекты — папки с вложенностью; в модели глубина не ограничена, в интерфейсе — **до 3 уровней** (перенос в папку разрешён, только если всё поддерево влезает в лимит).
- Карточка проекта — модель **«Намерение → Действие → Упование»**:
  1. **Намерение** — свободный текст «зачем», необязательный; в свёрнутом виде — первая строка + «ещё», по тапу раскрывается; карандаш — редактирование.
  2. **Подпроекты** (если есть или глубина позволяет — «+ Подпроект»).
  3. **Действие** — задачи без раздела, затем разделы (как в Todoist). У раздела: своё Намерение (такое же поведение), «+» задача в раздел, меню «…»: переименовать, удалить.
  4. «Показать выполненные (N)».
  5. **Упование** — заглушка ИИ-рекомендаций (дуа, доп. намаз, азкары), без логики.
- Шапка проекта: название родителя; звезда — избранное; «настройки»: папка, сфера, тег намерения, «В архив», «Удалить». Тап по названию — переименование.
- **Удаление проекта** удаляет его подпроекты, разделы и все их задачи — после подтверждения с подсчётом, что удалится (с советом отправить в архив, если проект просто завершён).
- **Удаление раздела** — задачи остаются в проекте без раздела.
- **Архив:** архивный проект скрыт из Обзора и выбора проекта; на экране «Архив проектов» — «Вернуть» или «Удалить».

## Теги

Пользовательские теги (имя уникально без учёта регистра; создаются в задаче или в Обзоре). Экран тега: активные задачи с тегом, избранное, цвет (палитра категорий), переименование, удаление (задачи остаются, тег у них пропадает); «+» — задача с этим тегом.

## Фильтры

Сохранённые фильтры из чипов, без языка запросов. Критерии: срок (Сегодня / Ближайшие 7 дней / Просрочено / Без срока), приоритет, сфера, тег намерения, теги. Внутри критерия — «ИЛИ», между критериями — «И». Только активные задачи. Экран фильтра: условия (редактируемые) + живой список задач; избранное; удаление.
