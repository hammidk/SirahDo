# Намаз, хиджра, местоположение, Профиль

## Времена намаза и окна

- Считаются **офлайн на устройстве** по координатам, методу расчёта и мазхабу (без внешнего API).
- 5 окон дня: Фаджр → Зухр, Зухр → Аср, Аср → Магриб, Магриб → Иша, Иша → Фаджр (следующего дня).
- Время показывается в часовом поясе устройства.

## Дата по хиджре

- По календарю Умм аль-Кура; если устройство его не поддерживает — табличный (арифметический) календарь.
- Ручная поправка в «Настройках намаза»: −2 … +2 дня (месяц в разных странах начинается по-разному).
- Сутки по хиджре считаются с полуночи, а не с Магриба.

## Профиль и Настройки намаза (меню аватара, см. [navigation.md](navigation.md))

- **Профиль:** имя (первая буква — на аватаре) и местоположение.
- **Настройки намаза:** метод расчёта, мазхаб, поправка хиджры и местоположение (тот же блок, что в Профиле).

- **Местоположение:** подпись места и координаты; «Определить по GPS» (запрос разрешения, подпись города через обратный геокодинг, если доступен); ручной выбор города — поиск по встроенному офлайн-списку (~50 городов России, СНГ, Турции, Ближнего Востока, Европы, Северной Америки); если города нет в списке — «Найти «…»» через системный геокодер (работает на телефоне, не на вебе).
- При первом запуске местоположение спрашивает онбординг (GPS или город вручную, можно отложить); отдельного автоматического запроса геолокации при старте нет.
- **Метод расчёта:** Muslim World League (по умолчанию), Egyptian, Karachi, Umm al-Qura, Dubai, Moonsighting Committee, ISNA (North America), Turkey (Diyanet).
- **Мазхаб (для Асра):** Шафии (по умолчанию) / Ханафи.
- **Поправка хиджры** — см. выше.
