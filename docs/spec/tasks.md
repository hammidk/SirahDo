# Задачи

Задача простая: что сделать, когда и в каком окне намаза. Где задачи лежат (Входящие, списки) — [lists.md](lists.md).

## Поля задачи

- **Название** (обязательно).
- **Срок:** дата + время (необязательно; без времени — задача «на день»).
- **Окно намаза** — см. [windows.md](windows.md): со временем подставляется само, без времени выбирается вручную или не выбирается.
- **Список** (пусто — Входящие).
- **Напоминания** (несколько): обычные и от времени намаза. «За N минут» считаются от срока; у задачи без времени — от 09:00 дня срока. «Точное время» работает и без срока.
- Под кнопкой **«Ещё»** (рядом — что из спрятанного заполнено): **Описание** (лёгкий markdown: **жирный**, _курсив_, списки «- » и «1. », ссылки `[текст](url)`) и **Повтор** (только при наличии срока, см. «Повторение» в [../SPEC.md](../SPEC.md)).

Чек-листа, приоритета, длительности, тегов, сферы, Ценности и Ожидаемого результата у задачи нет.

## Компактный и полный вид

- **Строка в списке:** круглый чекбокс, название, первая строка описания без разметки, метаданные мелким текстом: срок (красный, если просрочено; иконка повтора, если повторяется), число напоминаний, окно намаза, список (на общих экранах).
- **Тап по строке → компактный вид** (нижний лист): название и чипы Срок / Окно намаза / Список / Напоминание; «Ещё» — описание. Список можно сменить прямо здесь. Иконка **⤢** открывает полную карточку: новую — с перенесённым черновиком, существующую — после сохранения правок.
- **Долгое нажатие по строке → сразу полная карточка**: все поля; описание с панелью форматирования (B, I, •, 1., ссылка, предпросмотр; Enter продолжает список, пустой пункт завершает его).
- «+» в любом месте открывает компактный вид с подставленными по контексту значениями (дата, окно, список).

## Порядок в списках

По сроку: сначала раньше; в пределах дня — со временем по времени, затем без времени; задачи без срока — в конце, по порядку создания.

## Выполнение

- Отметка чекбокса → плашка «Задача выполнена · Отменить» (5 секунд). **Отменить** возвращает задачу точно как была (включая правило повтора) и удаляет созданное следующее вхождение.
- **Повторяющаяся задача** при выполнении остаётся выполненной (без правила повтора), а следующее вхождение создаётся новой задачей с той же настройкой (дата — следующая по правилу; для «N раз» счётчик уменьшается). Напоминания ставятся только для текущего вхождения.
- Выполненную задачу можно вернуть в работу (в списке — «Показать выполненные»).
- Удаление — с подтверждением, окончательное.
