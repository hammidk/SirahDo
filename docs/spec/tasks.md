# Задачи

## Поля задачи

- Название (обязательно); описание (лёгкий markdown: **жирный**, _курсив_, списки «- » и «1. », ссылки `[текст](url)`).
- Чек-лист (подзадачи-галочки).
- Срок: дата + время (необязательно; без времени — задача «на весь день»); длительность в минутах; повтор (только при наличии срока, см. «Повторение» в [../SPEC.md](../SPEC.md)).
- Напоминания (несколько). «За N минут» считаются от срока; у задачи без времени — от 09:00 дня срока. «Точное время» работает и без срока.
- Приоритет П1–П4; пользовательские теги (несколько); тег намерения; проект и раздел (пусто — Входящие); сфера жизни; окно намаза (из 5, в день срока или сегодня); Ценность; Ожидаемый результат.
- После выполнения: время начала и окончания, короткий комментарий-итог, причина переноса (если переносилась).

## Компактный и полный вид

- **Строка в списке:** круглый чекбокс (цвет обводки — приоритет), название, первая строка описания без разметки, метаданные мелким текстом: срок (красный, если просрочено; иконка повтора, если повторяется), число напоминаний, окно намаза, прогресс чек-листа, приоритет, теги, тег намерения, сфера, проект (на общих экранах), Ценность.
- **Тап по строке → компактный вид** (нижний лист): название, короткое описание, чипы Срок / Напоминание / Приоритет / Теги / Проект (с разделом) / Сфера; если задано окно намаза — чип окна с возможностью снять. Проект можно сменить прямо здесь. Иконка **⤢** открывает полную карточку: новую — с перенесённым черновиком, существующую — после сохранения правок.
- **Долгое нажатие по строке → сразу полная карточка** со всеми полями, описанием с панелью форматирования (B, I, •, 1., ссылка, предпросмотр; Enter продолжает список, пустой пункт завершает его) и кнопкой «▶ Начать» (отмечает время начала).
- «+» в любом месте открывает компактный вид с подставленными по контексту значениями.

## Выполнение

- Отметка чекбокса → плашка «Задача выполнена · Итог · Отменить» (5 секунд).
  - **Отменить** — возвращает задачу точно как была (включая правило повтора) и удаляет созданное следующее вхождение.
  - **Итог** — лист: «Как прошло?» (виден ожидаемый результат), время начала (по желанию) и окончания. Можно пропустить.
- **Повторяющаяся задача** при выполнении остаётся в Истории как выполненная (без правила повтора), а следующее вхождение создаётся новой задачей с той же настройкой (дата — следующая по правилу; для «N раз» счётчик уменьшается; чек-лист сброшен). Напоминания ставятся только для текущего вхождения.
- Выполненную задачу можно вернуть в работу.
- Удаление — с подтверждением.

## Перенос

Если срок активной задачи сдвигают на более позднюю дату, прежняя дата запоминается (для Истории), а в полной карточке появляется необязательное поле «Причина переноса».
