# Сегодня

Первая вкладка главного экрана (над ней — верхняя панель с аватаром и вкладками, см. [navigation.md](navigation.md)). День показан **лентой окон намаза**: дела лежат в том окне, к которому привязаны ([windows.md](windows.md)). Шкалы по часам здесь нет — она в Календаре.

Порядок блоков сверху вниз:

1. **Ориентир намаза** — один активный ориентир без слова «сейчас»: фон bg-hover, жёлтая полоска слева, полоса прогресса до следующего намаза.
   - Сверху маленькой подписью — дата: «Пт, 25 сентября · 14 Раби ас-сани 1448» (день недели, число, хиджра — см. [prayer-profile.md](prayer-profile.md)). Отдельной шапки с датой нет.
   - Заголовок — намаз, время которого уже наступило; строка — «До {следующего намаза} — {осталось}, в {время}». Длительность словами: «42 минуты», «3 часа 2 минуты», «меньше минуты» (округление вверх).
   - Цикл состояний: после полуночи до Фаджра — без заголовка, только «До Фаджра — …»; **Фаджр** → до Зухра; **Зухр** → до Асра; **Аср** → до Магриба; **Магриб** → до Иши; **Иша** → до Фаджра следующего дня. Восход отдельным состоянием не выделяется.
   - Пересчитывается в реальном времени (раз в 10 секунд и при возврате в приложение).
   - Без местоположения — та же подпись с датой и приглашение «Укажите местоположение» → экран «Профиль».
2. **В течение дня · N** — сворачиваемый блок (по умолчанию развёрнут): события «весь день», задачи на сегодня без окна намаза и привычки на сегодня без окна. Пустой блок не показывается.
3. **Просрочено · N** (если есть) — сворачиваемый блок: активные задачи со сроком раньше сегодняшнего; справа — «Перенести на сегодня» (переносит дату, время и окно сохраняются).
4. **Лента 5 окон** — по порядку дня: Фаджр → Зухр, Зухр → Аср, Аср → Магриб, Магриб → Иша, Иша → Фаджр.
   - Заголовок окна: название и время («Зухр → Аср · 12:58–15:41»), счётчик «сделано из всего», справа «+» — задача в это окно.
   - Внутри: события со временем, затем задачи (со временем — по времени, потом без времени), затем привычки этого окна. Привычка отмечается прямо здесь: цель 1 — кружок-переключатель, цель больше 1 — «+1».
   - **Текущее окно** выделено жёлтым акцентом и развёрнуто. Прошедшие окна свёрнуты до заголовка (если в них осталось несделанное — счётчик это показывает), будущие развёрнуты. Любое окно разворачивается тапом по заголовку.
   - Пустое окно — только заголовок с «+».
   - Тап по задаче — компактный вид ([tasks.md](tasks.md)); по событию — событие; по привычке — её карточка.
   - Без местоположения окна не считаются: вместо ленты — один общий список дел на сегодня.
5. **Итог дня** — число выполненных сегодня задач и привычек и заметка о дне ([day-summary.md](day-summary.md)). После Магриба (без местоположения — после 18:00) и ночью до Фаджра блок выделен.

**Ночь до Фаджра.** После полуночи и до Фаджра идёт ночное окно, начавшееся накануне. В это время над лентой показывается блок «До Фаджра»: дела сегодняшней даты со временем до Фаджра и привычки ночного окна (например, витр), ещё не отмеченные сегодня. После Фаджра блок остаётся, только если в нём есть дела со временем. День во всём приложении меняется в полночь: отметка привычки в 04:30 засчитывается сегодняшней дате.

На «Сегодня» попадают только задачи со сроком на сегодня и просроченные; задачи без срока живут во Входящих и списках. Привычки — те, что запланированы на сегодня.
«+» — новая задача на сегодня, окно — текущее (его можно сменить или убрать).
Экран обновляется раз в 30 секунд и при возврате в приложение (смена дня в полночь, смена текущего окна).
