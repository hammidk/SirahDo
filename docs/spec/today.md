# Сегодня

Главная вкладка. Справа в шапке — шестерёнка → Профиль. Порядок блоков сверху вниз:

1. **Ориентир намаза** — один активный ориентир, без списка 5 окон и без слова «сейчас»: текущее состояние видно по подсветке блока (фон bg-hover, жёлтая полоска слева, полоса прогресса до следующего намаза).
   - Сверху маленькой подписью — дата: «Пт, 25 сентября · 14 Раби ас-сани 1448» (день недели, число, хиджра — см. [prayer-profile.md](prayer-profile.md)). Отдельной шапки с датой нет.
   - Заголовок — намаз, время которого уже наступило; строка — «До {следующего намаза} — {осталось}, в {время}». Длительность словами: «42 минуты», «3 часа 2 минуты», «меньше минуты» (округление вверх).
   - Цикл состояний: после полуночи до Фаджра — без заголовка, только «До Фаджра — …»; **Фаджр** → до Зухра; **Зухр** → до Асра; **Аср** → до Магриба; **Магриб** → до Иши; **Иша** → до Фаджра следующего дня. Восход отдельным состоянием не выделяется (заголовок «Фаджр» держится до Зухра).
   - Пересчитывается в реальном времени (раз в 10 секунд и при возврате в приложение).
   - Без местоположения — та же подпись с датой и приглашение «Укажите местоположение» → Профиль.
2. **Без времени · N** — сворачиваемый блок (шеврон поворачивается, высота меняется плавно; по умолчанию развёрнут): события «весь день» и активные задачи на сегодня без времени. Сначала задачи без окна намаза, затем по окнам дня (у задачи видна метка окна), внутри — по приоритету. Пустой блок не показывается.
3. **Просрочено · N** (если есть) — такой же сворачиваемый блок: активные задачи со сроком раньше сегодняшнего; справа — «Перенести на сегодня» (переносит дату, время и окно сохраняются).
4. **Расписание** — шкала дня как в Календаре (режим «День»): события и задачи со временем — блоками по времени (задача — длительностью, по умолчанию 30 мин), пересекающиеся — рядом; намазы — несдвигаемые линии-якоря с подписью; линия текущего времени. У задачи на шкале — кружок «выполнить» (с плашкой «Итог / Отменить»); тап по блоку — компактный вид задачи / событие; тап по пустому часу — новая задача на этот час. Шкала начинается за час до текущего времени (или с часа самого раннего дела дня, если оно раньше) и идёт до 24:00 — пустые утренние часы не показываются.
5. **Итоги дня / Вечер:** число выполненных сегодня задач и привычек; кнопка «Анализ дня → дневник» (или «Открыть запись», если она есть). После Магриба (без местоположения — после 18:00) и ночью до Фаджра блок выделен.

На «Сегодня» попадают только задачи со сроком на сегодня и просроченные; задачи без срока живут во Входящих и проектах. Привычки на этом экране не показываются (они в Трекере). «+» — новая задача на сегодня.
Экран обновляется раз в 30 секунд и при возврате в приложение (смена дня в полночь, линия времени).
